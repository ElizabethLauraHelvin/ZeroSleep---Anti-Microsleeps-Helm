# ZeroSleep – Anti-Microsleep Smart Helmet

ZeroSleep is an IoT-based smart helmet designed to detect driver drowsiness in real time. The system monitors eye conditions, heart rate, and head movements to identify potential drowsiness and activate an alert using a buzzer and vibration motor.

## System Components

- **ESP32** – Reads sensor data and controls the alert components.
- **MAX30102** – Measures heart rate.
- **MPU6050** – Detects head movement and head angle.
- **Webcam** – Captures the driver's face for eye detection.
- **Python & CNN** – Processes webcam images to classify eye conditions as Opened or Closed.
- **FastAPI Backend** – Handles data processing and communication with the database.
- **React Frontend** – Displays real-time monitoring data through a dashboard.
- **SQLite** – Stores sensor and eye detection data.

## Requirements

Make sure the following software is installed:

- Python 3
- Node.js and npm
- Git
- Visual Studio Code (recommended)

## Installation and Setup

### 1. Webcam Detection

The webcam detection system uses a dedicated Python virtual environment named `.venv-webcam`.

Open a terminal in the project root directory:

```bash
.venv-webcam\Scripts\activate
```

After activation, the terminal should display:

```text
(.venv-webcam) C:\...\ZeroSleep>
```

Run the webcam detection script:

```bash
python camera-detection.py
```

**Note:** If the virtual environment has not been created yet, create it first:

```bash
python -m venv .venv-webcam
.venv-webcam\Scripts\activate
```

Install the required Python dependencies if a requirements file is available for the webcam environment.

### 2. Backend Setup

Open a new terminal in VS Code and navigate to the backend directory:

```bash
cd dashboard\backend
```

Create a Python virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment:

```bash
.venv\Scripts\activate
```

After successful activation, the terminal should display:

```text
(.venv) C:\...\ZeroSleep\dashboard\backend>
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the backend server:

```bash
python run.py
```

### 3. Frontend Setup

Open another terminal in VS Code and navigate to the frontend directory:

```bash
cd dashboard\frontend
```

Install the required dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm run dev
```

If successful, the terminal will display a local development URL:

```text
Local: http://localhost:5173/
```

Open the URL in your browser to access the ZeroSleep dashboard.

## Running the Complete System

To run the complete ZeroSleep system, use separate terminals for each component:

| Terminal | Component | Command |
|---|---|---|
| 1 | Webcam Detection | `python camera-detection.py` |
| 2 | Backend | `python run.py` |
| 3 | Frontend | `npm run dev` |

Make sure the ESP32 is connected to the computer and the required sensors are properly configured before starting the monitoring process.

## Database

ZeroSleep uses SQLite as its database. The database file is:

```text
helmet_data.db
```

It contains two main tables:

- `esp32_sensor_data` – Stores sensor readings and monitoring data received from the ESP32.
- `eye_detection` – Stores eye detection records generated by the webcam detection system.

## Alert Mechanism

The system determines the driver's condition based on the monitored parameters:

- Eye condition detection.
- Heart rate monitoring.
- Head angle and nodding detection.

When the required drowsiness conditions are met, the ESP32 activates the buzzer and vibration motor to alert the driver.

## Notes

- The `.venv-webcam` and `dashboard/backend/.venv` directories are local Python virtual environments and should not be uploaded to GitHub.
- The `node_modules` directory should also be excluded from GitHub.
- Install dependencies using the provided requirements file and `npm install`.
- Webcam detection requires a connected webcam and the trained CNN model.
